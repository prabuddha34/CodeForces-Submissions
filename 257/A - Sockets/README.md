He's got <span class="tex-span"><i>n</i></span> supply-line filters to plug the devices, the <span class="tex-span"><i>i</i></span>-th supply-line filter has <span class="tex-span"><i>a</i><sub class="lower-index"><i>i</i></sub></span> sockets.</p><p>Overall Vasya has got <span class="tex-span"><i>m</i></span> devices and <span class="tex-span"><i>k</i></span> electrical sockets in his flat, he can plug the devices or supply-line filters directly. The device (or the supply-line filter) is considered plugged to electricity if it is either plugged to one of <span class="tex-span"><i>k</i></span> electrical sockets, or if it is plugged to some supply-line filter that is in turn plugged to electricity. </p><p>What minimum number of supply-line filters from the given set will Vasya need to plug all the devices he has to electricity?
