The gameplay is as follows. </p><p>There are two armies on the playing field each of which consists of <span class="tex-span"><i>n</i></span> men (<span class="tex-span"><i>n</i></span> is always even). It may happen that several soldiers had been indicated the same target. Killed soldiers do not participate in the game anymore. </p><p>The game "GAGA" consists of three steps: first Valera makes a move, then Arcady, then Valera again and the game ends. </p><p>You are asked to calculate the maximum total number of soldiers that may be killed during the game. </p></div><div class="input-specification"><div class="section-title">Input</div><p>The input data consist of a single integer <span class="tex-span"><i>n</i></span> (<span class="tex-span">2 ≤ <i>n</i> ≤ 10<sup class="upper-index">8</sup></span>, <span class="tex-span"><i>n</i></span> is even).
