What is the minimum number of elements you need to remove to make it good? You can delete an arbitrary set of elements.</p></div><div class="input-specification"><div class="section-title">Input</div><p>The first line contains the integer $$$n$$$ ($$$1 \le n \le 120000$$$) — the length of the given sequence.</p><p>The second line contains the sequence of integers $$$a_1, a_2, \dots, a_n$$$ ($$$1 \le a_i \le 10^9$$$).</p></div><div class="output-specification"><div class="section-title">Output</div><p>Print the minimum number of elements needed to be removed from the given sequence in order to make it good.
