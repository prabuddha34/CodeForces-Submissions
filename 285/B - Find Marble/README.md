Petya's got <span class="tex-span"><i>n</i></span> non-transparent glasses, standing in a row. Note that the positions are indexed but the glasses are not.</p><p>First Petya puts a marble under the glass in position <span class="tex-span"><i>s</i></span>. Then he performs some (possibly zero) shuffling operations. Consider all glasses are moving simultaneously during one shuffling operation. The second line contains <span class="tex-span"><i>n</i></span> space-separated integers: <span class="tex-span"><i>p</i><sub class="lower-index">1</sub>, <i>p</i><sub class="lower-index">2</sub>, ..., <i>p</i><sub class="lower-index"><i>n</i></sub> (1 ≤ <i>p</i><sub class="lower-index"><i>i</i></sub> ≤ <i>n</i>)</span> — the shuffling operation parameters.
