As we know, each ticket has a number that is a positive integer. Its length equals <span class="tex-span"><i>n</i></span> (<span class="tex-span"><i>n</i></span> is always even). Petya calls a ticket lucky if the ticket's number is a lucky number and the sum of digits in the first half (the sum of the first <span class="tex-span"><i>n</i> / 2</span> digits) equals the sum of digits in the second half (the sum of the last <span class="tex-span"><i>n</i> / 2</span> digits).
